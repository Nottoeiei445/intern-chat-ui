### 📌 สถาปัตยกรรมหลัก: Feature-Based Structure
* **วัตถุประสงค์:** แยกซอร์สโค้ดตามกลุ่มหน้าที่ของโมดูล (เช่น ระบบแผนที่ ระบบแชท ระบบยืนยันตัวตน)
* **การจัดวางโครงสร้าง:** * `src/app` ทำหน้าที่จัดการระบบเส้นทาง (Routing) และโครงสร้างหน้าเว็บ (Layout) 
    * ส่วนลอจิกการทำงานและองค์ประกอบภายในหลักจะแยกไปอยู่ใน 
    * `src/component` จัดเก็บคอมโพเนนต์ส่วนกลาง ที่มีการเรียกใช้งานซ้ำจากหลายฟีเจอร์ทั่วทั้งแอปพลิเคชัน รวมถึงเป็นที่เก็บองค์ประกอบ UI พื้นฐานที่ถูกสร้างหรือนำเข้ามาจากระบบของ shadcn/ui
    * `src/features` โมดูลหลักของแอปพลิเคชัน แยกกลุ่มโฟลเดอร์ตามฟังก์ชันการทำงานจริง (เช่น map, chat, auth) โดยภายในแต่ละฟีเจอร์จะมีส่วนประกอบย่อย เช่น components, services, hooks และ types ของตัวเอง เพื่อให้โค้ดแยกขาดจากกันอย่างสมบูรณ์
    * `src/lib` โฟลเดอร์จัดเก็บฟังก์ชันช่วยเหลือและคอนฟิกูเรชันส่วนกลางที่แชร์ใช้งานร่วมกันทั่วทั้งแอปพลิเคชัน โดยแยกออกเป็นไฟล์ตามหน้าที่หลักดังนี้:
        * `api-client.ts`: ตัวครอบ Fetch ที่ยุบลอจิกซ้ำซ้อน (เช่น การแปะ Base URL, แอบแนบ Token, ดัก Error) มารวมไว้ที่เดียว เพื่อให้ไฟล์อื่นสามารถเรียกใช้งาน API ได้สั้น กระชับ และคลีนที่สุด
        * `env.ts`: ศูนย์กลางการดึงค่า Environment Variables มาประกาศจับคู่กับระบบ Type Safety เพื่อให้มีระบบ Autocomplete ป้องกันการเรียกใช้ชื่อคีย์ผิดพลาด
        * `storage.ts`: โมดูลจัดการบันทึกข้อมูลบนบราวเซอร์ โดยแยกฝั่ง Cookies (สำหรับเก็บ Access Token) และ LocalStorage (สำหรับเก็บข้อมูลทั่วไป) 
        * `utils.ts`: แหล่งรวมฟังก์ชันอรรถประโยชน์ทั่วไป เช่น ฟังก์ชัน "cn" ที่ใช้ผสานคลาสของ Tailwind CSS และจัดการคลาสที่ซ้ำซ้อนให้ทำงานร่วมกันได้อย่างถูกต้อง
    * `src/store` จัดเก็บระบบบริหารสถานะส่วนกลาง (Global State Management) ผ่านไลบรารี Zustand ทำหน้าที่เป็นท่อส่งข้อมูลสากลเพื่อแชร์สเตตข้ามโมดูลโดยตรง เช่น การส่งต่อข้อมูลคำสั่งและเงื่อนไขตัวกรองระหว่างระบบแชท AI 
    * `.env.local` (ไฟล์นอกโฟลเดอร์ src) ใช้สำหรับจัดเก็บค่าตัวแปรสภาพแวดล้อมที่เป็นความลับ โดยไฟล์นี้จะถูกยกเว้นจากการอัปโหลดขึ้นระบบ GitHub เพื่อความปลอดภัย

## โครงสร้างภายในโฟลเดอร์ src/app (Routing & Layout)

### 📄 layout.tsx (Root Layout)
* **หน้าที่หลัก:** กำหนดโครงสร้างนอกสุดของแอปพลิเคชัน คุมระบบฟอนต์หลัก และติดตั้ง Global Providers ครอบทั้งระบบ
* **ส่วนประกอบหลัก:** ThemeProvider (บังคับระบบเป็น Dark Mode), ToastProvider (ระบบแจ้งเตือนป๊อปอัพ), AuthProvider (จัดการเซสชันผู้ใช้งาน)

### 📄 page.tsx (Main Workspace)
* **หน้าที่หลัก:** หน้าแรกของระบบ ทำหน้าที่จัดเลย์เอาต์หน้าจอแผนที่หลัก และใช้สเตตควบคุมการพับเปิด-ปิดแผงแชทฝั่งซ้าย
* **คอมโพเนนต์หลักที่เรียกใช้:**
    * `<MapDashboard />` (จาก src/features/map) -> โหลดเอนจินแผนที่ MapLibre GL JS เรนเดอร์ข้อมูลเชิงพื้นที่
    * `<ChatFeature />` (จาก src/features/chat) -> อินเตอร์เฟสกล่องข้อความแชทสำหรับส่งคำสั่งไปประมวลผลกับ AI
    * `<MapLegend />` (จาก src/features/map) -> แผงคำอธิบายสัญลักษณ์และขอบเขตสีเลเยอร์ (พิกัดขยับหลบแผงแชทออโต้)
    * `<AuthWidget />` (จาก src/features/auth) -> วิดเจ็ตแสดงข้อมูลโปรไฟล์และสถานะบัญชีผู้ใช้งาน
    * `<LayerManager />` (จาก src/features/map) -> หน้าต่างจัดการเปิด-ปิด และนำเข้า/ส่งออกข้อมูลเลเยอร์บนแผนที่

### 📄 globals.css (Global Stylesheet)
* **หน้าที่หลัก:** เป็นศูนย์กลางกำหนดสไตล์ในระดับสากล (Global Styles) และตั้งค่าระบบธีมสี (CSS Variables) ของแอปพลิเคชันทั้งหมด
* **ส่วนประกอบหลัก:** โหลด Directives หลักของ Tailwind CSS และเป็นที่จัดเก็บชุดค่าสีพื้นฐานสำหรับระบบของ shadcn/ui (เช่น ค่าสีระบบ bg-background, border-border, และ text-primary) เพื่อควบคุมให้คอมโพเนนต์และฟีเจอร์ต่าง ๆ ทั่วทั้งแอปพลิเคชันแสดงผลสอดคล้องกันตามมาตรฐานดีไซน์ระบบ  

### 📁 login/page.tsx (หน้าต่างเข้าสู่ระบบ)
* **หน้าที่หลัก:** หน้า Wrapper สำหรับการ login
* **คอมโพเนนต์หลักที่เรียกใช้:** `<LoginForm />` (จาก src/features/auth) เพื่อทำหน้าที่ตรวจสอบและยืนยันสิทธิ์ผู้ใช้งาน

### 📁 register/page.tsx (หน้าต่างลงทะเบียน)
* **หน้าที่หลัก:** หน้า Wrapper สำหรับการ register
* **คอมโพเนนต์หลักที่เรียกใช้:** `<RegisterForm />` (จาก src/features/auth) เพื่อทำหน้าที่รับและบันทึกข้อมูลสมัครสมาชิก

### 📁 setting/keys/page.tsx (หน้าต่างจัดการรหัส API Keys)
* **หน้าที่หลัก:** หน้า Wrapper ที่ให้ user ตั้งค่า api key 
* **กลไกภายใน:** ใช้ useAuth ดักเช็กสิทธิ์อีเมล, ครอบหน้าเว็บด้วย `<AuthGuard>` กันผู้ที่ยังไม่ได้ล็อกอิน และเรียกใช้คอมโพเนนต์ `<ApiKeyManager />` เพื่อบันทึกรหัสผ่านเข้าสู่ระบบ

### 📁 api/local-chat/route.ts 
* **หน้าที่หลัก:** API Route Handler ของ Next.js ดักรับ HTTP POST สำหรับส่งข้อความไปหาเซิร์ฟเวอร์ Local LLM
* **กลไกภายใน:** (ปัจจุบันสลับไปให้หลังบ้านคุยกับ AI แทนแล้ว) เก็บไว้เป็นท่อสำรองสำหรับทดสอบระบบแชทแบบ Local ผ่านฟังก์ชัน chatWithOllama โดยไม่ต้องพึ่งพาเซิร์ฟเวอร์หลังบ้าน

## โครงสร้างภายในโฟลเดอร์ src/components

### 📁 ui/
* **หน้าที่หลัก:** จัดเก็บคอมโพเนนต์ UI พื้นฐาน ที่ติดตั้งผ่านระบบของ shadcn/ui (เช่น button, dialog, badge, textarea, tooltip) เพื่อเป็นคลังออบเจกต์ส่วนกลางให้ทุกฟีเจอร์ ดึงไปใช้งานร่วมกันภายใต้มาตรฐานและดีไซน์เดียวกัน

### 📄 theme-provider.tsx
* **หน้าที่หลัก:** ทำหน้าที่เป็นตัวกระจายบริบทสกินหน้าจอ (Theme Context Provider) ครอบแอปพลิเคชัน
* **กลไกการทำงาน:** เรียกใช้งานคอมโพเนนต์ NextThemesProvider จากแพ็กเกจ `next-themes` เพื่อส่งต่อสเตตและเปิดสิทธิ์ระบบควบคุมการเปลี่ยนโหมดมืด/สว่าง (Dark/Light Mode) ไปยังทุกส่วนภายในแอป

### 📄 mode-toggle.tsx
* **หน้าที่หลัก:** คอมโพเนนต์ปุ่มสำหรับกดสลับสกินหน้าจอระบบ ระหว่างโหมดสว่าง (Light) และโหมดมืด (Dark)
* **กลไกการทำงาน:** เรียกใช้งาน Hook `useTheme` จากระบบเพื่อตรวจสอบสกินปัจจุบัน และสั่งสลับสถานะ ค่าธีมผ่านฟังก์ชัน `setTheme` โดยภายในตัวปุ่มมีการใช้ Tailwind CSS ควบคุมแอนิเมชันและการซ่อน/แสดง ไอคอนรูปพระอาทิตย์ (Sun) และพระจันทร์ (Moon) ให้หมุนสลับและย่อขยาย (`rotate`, `scale`) ตามสถานะธีมปัจจุบันอย่างนุ่มนวล
